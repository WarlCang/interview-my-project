# interview-my-project

[English](README.md) | **中文**

> **Vibe coding 帮你做出了项目。`interview-my-project` 让它真正属于你。**

一个只面试**你的项目**的 AI 面试官。它读你的代码库、读你本地的 Claude Code 会话记录,
然后像真正的资深工程师一样,针对*这个项目*把你问到底——在真面试官这么做之前,先替他做一遍。

```
🎙️  这个项目里,什么东西是你试了但没做成的?

    > 呃……基本上一次就跑通了

🔴  你的会话记录显示,你跟误拒问题缠斗了两天,最后手动改了检索分数门槛。
    面试官闻得出这种破绽。我们来聊聊当时到底发生了什么。
```

## 为什么

你用 AI agent 做出了一个作品集项目。能跑,也写进简历了。

然后面试官打开你的仓库,问:*"讲讲你为什么这么设计。"*

所有模拟面试工具都按职位描述出题,所有 AI 家教都按知识点教学。**没有一个工具会针对
你真正写出来的代码面试你**——更没有工具能看到你本地 agent 会话记录里埋着的决策过程:
你放弃过的方案、你反复踩过的坑、你没看内容就采纳的 diff。

这个工具问的,恰恰就是这些。

## 安装

一行命令,任意 agent(Claude Code、Cursor、Codex CLI、Copilot、DeepSeek、OpenCode 等):

```bash
npx skills add WarlCang/interview-my-project -g
```

然后在你想被面试的仓库里打开你的 agent,粘贴第一句话:

```
针对这个项目面试我,不用留情面。
```

### Claude Code 插件(附带 /interview-me 命令和 ingest 子代理)

```
/plugin marketplace add WarlCang/interview-my-project
/plugin install interview-my-project@interview-my-project
```

然后在任意想被面试的仓库里:

```
/interview-me
```

模式:`/interview-me quick`(5 题)· `/interview-me deep`(12 题 + 一次完整数据流
追问)· `/interview-me focus auth`(只钻一个子系统)· `/interview-me role pm`
(按目标岗位校准——同一个仓库,面 PM、设计、数据还是工程岗,是完全不同的一场
面试,提问的也换成*那个*行当里最难缠的资深面试官)。

支持任意语言——英文、中文或其他(`/interview-me lang zh`,或者直接用中文回答,
面试官会跟上)。人设和标准不变:那股怀疑劲儿是按语言原生重写的,不是翻译腔。

### 没有 `skills` CLI?手动安装

整场面试就是一个自包含的 [Agent Skills](https://agentskills.io) 格式技能,不依赖任何
Claude 专属机制:把 `skills/interview-my-project/` 拷进你 agent 的 skills 目录,或者
直接让任意 agent 读这个文件:

```
读取 skills/interview-my-project/SKILL.md 并遵照执行,针对这个仓库面试我。
```

面试体验在所有 agent 上完全一致。哪里找得到会话历史,哪里就有基于历史的问题——
Claude Code 和 Codex 的日志自动发现,仓库自带的记录(进度日志、ADR、会话笔记)在
任何 agent 上都有效;什么都找不到时,你得到的是纯仓库版面试。

## 工作原理

1. **摄取** — 扫描仓库结构和关键决策,再挖掘你本地 `~/.claude/projects/` 会话记录里的
   方案转向、报错-修复循环、以及你没经讨论就采纳的 diff。一切都留在你的机器上。
2. **出题** — 生成一份按重要性排序的题库,全是资深面试官真会问的:架构选择、X 还是 Y
   的取舍、失效模式、规模上限——还有只有你的会话记录才能支撑的问题("为什么放弃了
   方案 X?")。
3. **拷问** — 终端里的一场真实面试。一次一题,含糊其辞就追问,评分毫不客气:
   🟢 扎实 / 🟡 发虚 / 🔴 守不住。
4. **教练** — 每个回答都会得到一份基于你真实代码的复盘:带 `file:line` 证据的判定、
   你*本该*给出的标准答案(**该这么说**)、拖累你的那句话(**别这么说**),以及——
   当诚实的答案很弱是因为项目本身弱的时候——能把答案升级的具体修复方案(**修一下**),
   汇总成一份它可以陪你一起实现的备战清单。答弱的题下次继续问。
5. **追踪** — 计分卡(`.interview/scorecard.json`)跨会话记录你的准备度和趋势,每场
   面试结束还会生成一张**准备度卡片**:1200×630、可直接截图分享的战绩总结。晒惨烈
   分数是一半乐趣,看它爬升是另一半。

## 面试是什么感觉

它扮演的是*真实*的面试官——而且是最难缠的那种:今年已经看过一百个 AI 生成的作品集
项目、默认你的也是其中之一的 bar-raiser。开场是"给我讲讲——讲点 README 里看不到的
东西",当面质疑你的所有权("你一直说'我们'——'我们'是谁?"),质疑项目本身的价值
("这东西我一个下午跟着教程做不出来吗?"),然后顺着**你说的话**往下钻——它从不靠
念你的代码来出戏。答出真东西,怀疑会松一拍:*"行,这是句实话。"* 这个反差就是训练。

没有琐碎问答,没有"什么是 REST"。每个问题都要过一道门槛:*盯着一个文件看 10 秒钟
答不出来的,才配问。*

- "为什么用 SQLite?这个决定到什么规模开始拖累你?迁移方案是什么?"
- "上游服务挂起了。一步步讲,用户会看到什么?"
- "最难缠的 bug 是哪个?"——*提问时它已经从你的会话记录里知道了真实答案。你要是
  把耗掉你两天的那个坑一笔带过,它会告诉你。*

## FAQ

**这算作弊工具吗?** 恰恰相反。面试实时辅助才是作弊;这个工具让你*真正搞懂自己的
项目*,以后根本不需要那种东西。

**数据会离开我的电脑吗?** 不会。仓库、会话记录、计分卡全部本地,跑在你自己的
agent 订阅上。这个技能本体就是 markdown 加一个 HTML 模板——没有遥测,没有任何
网络请求。完整边界见 [SECURITY.md](SECURITY.md)。

**这个仓库没有会话记录?** 照样能用——你会得到纯仓库版的面试,只是少了基于历史
记录的那类问题。带有 agent 写下的进度笔记或 ADR 的仓库能找回其中大部分,任何
agent 都一样。
